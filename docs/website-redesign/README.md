# meridianflow.ca redesign

Working files for the repositioning of the Meridian service website (not the desktop app).

- `meridian-repositioning-brief.html` — diagnosis, positioning, Find/Build/Run offer, information architecture, full homepage copy, conversion fixes, design and interaction briefs, implementation plan, unresolved questions.
- `meridian-homepage.html` — homepage prototype rendering the new copy and visual direction. Fragment (no `<html>`/`<head>`); wrap it or paste into a page template. Fonts load from Google Fonts. Form submit and calendar are stand-ins to replace with a real form endpoint and a Cal.com/Calendly embed.

Bracketed values (`[Founder name]`, `[X] h`) are facts to fill in before publishing.
